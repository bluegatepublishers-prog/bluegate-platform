# SARTHI Assessment Engine Specification

**Version:** 1.0

**Status:** Draft

**Module:** Assessment Engine

**Product:** SARTHI

**Owner:** Edora Learning Pvt. Ltd.

---

# Purpose

The Assessment Engine provides a unified platform for creating, delivering, evaluating, analyzing, and improving assessments across all educational institutions supported by SARTHI.

The engine supports formative, summative, competency-based, adaptive, practical, and AI-assisted assessments.

---

# Vision

The Assessment Engine shall become the core academic evaluation service for the entire SARTHI ecosystem, enabling reliable, fair, secure, and meaningful assessment experiences.
